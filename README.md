# Bank Loan Prediction

## Project Description
This project predicts loan approval for bank applicants using machine learning (Logistic Regression).  
It demonstrates full workflow: SQL database creation, data collection, EDA, and ML modeling.

## Features
- SQL database `data_model` with `bank_loans` table
- Python EDA with matplotlib & seaborn
- Machine Learning model to predict loan status
- Dataset: `bank_loans.csv`
